# 💻 Laptop Request Catalog Item

## 📘 Overview
This project automates the process of requesting laptops within an organization using **ServiceNow’s Service Catalog**.  
It provides a dynamic form, automated workflow, and reset functionality — replacing manual, error-prone processes.

---

## 🚀 Features
- Dynamic catalog item for laptop requests  
- Real-time field behavior using Catalog Client Scripts  
- Form reset option with:
  ```javascript
  function resetForm() {
      g_form.clearForm();
      alert("The form has been reset.");
  }
